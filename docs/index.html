What’s live now

The dashboard streams Fintraffic Digitraffic AIS over MQTT in your browser. No API key. Coverage is Finnish waters and the northern Baltic (roughly 17–30°E, 58–66°N). Positions are official open data, not invented.

A REST snapshot loads first so ships appear immediately; the WebSocket then moves them in real time. Route trails are built from positions received in this session. Digitraffic does not publish a historical track API.

Global coverage (optional)

aisstream.io offers a free global AIS WebSocket, but it blocks direct browser connections (CORS). A key pasted here is stored only in this browser’s localStorage and is never sent to our server. The app will try the stream; if the browser is blocked, you’ll see how to enable a 15-minute GitHub Actions snapshot instead.

  1. Sign in at aisstream.io/apikeys with GitHub and create a free API key.
  2. Browser use is usually blocked. For a world snapshot every 15 minutes, add the key as repo secret AISSTREAM_API_KEY on piyaster11/ship-tracker (Settings → Secrets and variables → Actions). The included workflow writes snapshot/global.json, which this page will pick up automatically.

Other feeds checked: Norwegian Kystverket is a raw TCP socket (not usable in a browser; outbound port was blocked from our test host). AISHub requires you to contribute your own AIS receiver. CetaHAV’s Baltic HTTP API did not return a body in time.
